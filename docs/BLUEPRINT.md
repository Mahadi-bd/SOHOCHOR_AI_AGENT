# LIFE EASY · সহচর — ব্লুপ্রিন্ট (জীবন্ত নথি)

এই ফাইলটি প্রকল্পের মূল সিদ্ধান্ত ও অবস্থা ধরে রাখে, যাতে নতুন ফিচার যোগ করতে গিয়ে মূল কাঠামো না ভাঙে। কোনো বড় পরিবর্তনের আগে এটা পড়ুন, পরে হালনাগাদ করুন।

## ১. লক্ষ্য
ফোনে চলা একটি ব্যক্তিগত AI সহকারী: দৈনন্দিন কাজ, রিপোর্ট, মিটিং, প্রেজেন্টেশন, ওয়েব লিংক পড়া, আইনি ঝুঁকি-সতর্কতা। বাংলা-প্রথম, ফোনে ডেটা, ব্যবহারকারীর নিজের API কী।

## ২. অপরিবর্তনীয় নিয়ম (এগুলো ভাঙা যাবে না)
1. **API কী কখনো রিপোতে নয়।** ব্যবহারকারী নিজের কী দেয়; কী থাকে Android Keystore (AES-256-GCM) দিয়ে এনক্রিপ্টেড।
2. **ডেটাবেস এনক্রিপ্টেড** (SQLCipher)। পাসফ্রেজ নষ্ট হলে ডেটা মোছা হয় না, ফাইল সরিয়ে রাখা হয়।
3. **ঝুঁকিপূর্ণ কাজে সর্বদা নিশ্চিতকরণ** (Risk.HIGH: মোছা, কল, SMS, ইমেইল)। ফোনের কাজ সিস্টেম স্ক্রিন খোলে, নিজে কিছু পাঠায় না।
4. **ওয়েবের লেখা ডেটা, নির্দেশ নয়।** fetch_url ফলাফল "UNTRUSTED" চিহ্নিত; শুধু https; লোকাল নেটওয়ার্ক ব্লক।
5. **ফাইলে বিপজ্জনক সূত্র নয়।** SafeFormula (HYPERLINK, WEBSERVICE, IMPORT* ইত্যাদি বাদ); CSV-তে ইনজেকশন প্রতিরোধ।
6. **টুল প্রোটোকল একটাই:** মডেল JSON {"tool","args"} দেয়; সব প্রোভাইডারে চলে। নতুন ক্ষমতা = নতুন `Tool` (নাম, help, risk)।
7. **স্পেস পার্সার ও রাইটার বিশুদ্ধ কোটলিন ও টেস্টযুক্ত।** নতুন ফরম্যাট যোগ করলে ফাইলটা LibreOffice/python দিয়ে খুলে যাচাই করুন, তারপর টেস্ট লিখুন।
8. **CI সবুজ না হলে মার্জ নয়** (টেস্ট + APK বিল্ড)।

## ৩. স্থাপত্য (স্তর)
UI (Compose) → ViewModel → **AgentEngine** (পরিকল্পনা → টুল → নিশ্চিতকরণ গেট → অডিট লগ) → **LlmRouter** (কী/মডেল ফলব্যাক) → HTTP (DoH ফলব্যাক, বাতিলযোগ্য)।
ডেটা: Room + SQLCipher (কথোপকথন, স্মৃতি, কাজ, অডিট)। ফাইল: অ্যাপ-প্রাইভেট ফোল্ডার; শেয়ার শুধু FileProvider দিয়ে।

## ৪. ফাইল ফরম্যাট ম্যাট্রিক্স
| ধরন | ফরম্যাট | নোট |
|---|---|---|
| ডকুমেন্ট | PDF, DOCX, ODT | ৬টি রঙের থিম, টেবিল, বুলেট |
| স্প্রেডশিট | XLSX, ODS, CSV | হেডার রঙিন, ফ্রিজ, সূত্র (নিরাপদ), CSV = UTF-8 BOM |
| প্রেজেন্টেশন | PPTX | শিরোনাম স্লাইড + কনটেন্ট স্লাইড |
| বান্ডেল | ZIP | `zip_documents` টুল বা "সব ফাইল ZIP" বোতাম |
| Google Sheets | XLSX/ODS/CSV খুলুন বা শেয়ার | সরাসরি API সংযোগ পরের ফেজে (Google সাইন-ইন লাগে) |

## ৫. ব্র্যান্ডিং ও সাবস্ক্রিপশন
PDF-এর শীর্ষে **LIFE EASY লোগো + নাম**, পাদটীকায় নাম। সরানো ভবিষ্যতে পেইড সাবস্ক্রিপশনের ফিচার: শুধু `Branding.enabled()` প্ল্যান দেখে বদলাবে। (দ্রষ্টব্য: যেকোনো PDF তৃতীয় পক্ষের টুলে এডিট করা যায়; সাবস্ক্রিপশন অ্যাপের ভেতরের অপশনকে নিয়ন্ত্রণ করে।)
